# 2026-11-05

- Source walks now exclude both project and home copy roots, resolved through links.
  The committed cross-copy regression failed before this fix; its two comparisons passed.
- File/folder conflicts are reported per source path and left in place; other files
  refresh. The engine filesystem API has no delete operation. Automatic replacement
  needs that API first, with the same ownership and resolved-path write guards.
- A plain Map accepts a file and descendants at once and can write over an implied
  directory. The new type-change fake rejects these operations. Node's real disk
  rejects them too: recursive mkdir under a file returned EEXIST here; writing over
  a directory returned EISDIR. Both type-change tests failed before the fix.
- The real-disk probe (`tests/real-disk.cjs`) runs in `tests/release.sh` and cleans up its fixtures.
- Follow-up: the queue serializes one destination spelling within one module instance;
  separate processes and path aliases do not share a lock. Resolved-path checks also
  do not lock links against an external writer changing them before a write.
  The copy is not atomic: interruption can leave mixed versions, repaired on retry.
  Death between the marker and ignore writes remains the documented visibility gap.
